HTMP Basic Example

A simple example of interactive rendering using HTMP with a title editor, counter, and todo list.

Repository: github.com/erlanggasatria-source/HTMP

This example demonstrates slot-based rendering. The title starts empty and the todo list starts empty, with no if conditional needed. The title updates immediately as the user types, and the todo list appears with working action buttons even though the initial data is truly empty.
